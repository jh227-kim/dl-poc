To-Be (dl-poc): as-is same layout; supply -> Kafka mail.events only.

Prereq: Docker Desktop + from dl-poc root: docker compose up -d

Install (use dl-poc venv or a dedicated venv):
  pip install -r to-be/requirements.txt

Ports (defaults, parallel with as-is 8000~):
  supply   http://localhost:8100
  search   http://localhost:8101
  mobile   http://localhost:8102
  graph    http://localhost:8103
  dashboard http://localhost:8104

Env (optional):
  KAFKA_BOOTSTRAP_SERVERS=localhost:9092
  KAFKA_INGEST_TOPIC=mail.events
  SUPPLY_SERVICE_URL=http://localhost:8100

--- 공급만 + Kafka에서 메시지 보기 (소비 서비스 없음) ---

1) Docker + (선택) 토픽 생성 — mail.events 가 없으면 한 번:
   cd dl-poc && scripts\kafka-smoke.bat
   (또는 수동: docker compose exec -T kafka kafka-topics --bootstrap-server kafka:29092 --create --if-not-exists --topic mail.events --partitions 1 --replication-factor 1)

2) 터미널 A — Kafka tail (메시지 확인):
   cd dl-poc
   docker compose exec -it kafka kafka-console-consumer --bootstrap-server kafka:29092 --topic mail.events --from-beginning

3) 터미널 B — To-Be 공급만:
   cd dl-poc
   venv\Scripts\pip install -r to-be\requirements.txt
   cd to-be\supply_service
   ..\..\venv\Scripts\uvicorn main:app --host 0.0.0.0 --port 8100

4) 메일 생성 (브라우저 또는 curl):
   curl -X POST http://localhost:8100/mails -H "Content-Type: application/json" -d "{\"title\":\"t\",\"body\":\"b\",\"sender\":\"s@test.com\"}"

터미널 A에 {"mail_id":"...", "action":"created"} 한 줄이 찍히면 수집 Kafka 반영된 것.
